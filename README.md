# STAT1500: Introduction to Statistical Computing

## 📘 Overview

This repository contains lecture notes for **STAT1500: Introduction to Statistical Computing**.
It is designed to help students and self-learners build a strong foundation in **R programming** and statistical computing.

> The course covers the basics of programming in R and introduction to statistical software; generating statistical plots; computing descriptive statistics; performing basic statistical procedures; fundamentals of numerical analysis; optimization; generating random numbers, performing simple simulations, and simulation-based inference.

---

## 🎯 Learning Objectives

* Understand core programming concepts in R
* Work with data types and data structures
* Perform data manipulation and cleaning
* Create statistical visualizations
* Apply basic statistical and numerical methods
* Develop reproducible analysis using R Markdown
* Explore simulation and computational techniques
